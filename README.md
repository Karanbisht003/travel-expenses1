

# Travel Expenses Management System

This is a simple Travel Expenses Management project that helps users
record and manage their travel-related expenses easily.

The project is designed for beginners to understand how expense tracking
applications work using basic web technologies.

---

## 🚀 Features

- Add travel expenses (transport, food, hotel, etc.)
- View list of all added expenses
- Calculate total travel expense
- Simple and user-friendly interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub

---

## 📂 Project Structure

- index.html – Main UI of the application  
- style.css – Styling of the project  
- script.js – Logic for adding and calculating expenses
